# 🛒 Amazon E-Commerce Simulation (Java)

This project is a simple **console-based E-commerce application** built in Java.  

##  Features
- User Authentication
  - Login system with username and password validation.
- **Product Management**  
  - Predefined product list with ID, name, and price.
  - View all available products.
- Cart Operations
  - Add products to cart by ID.
  - Remove products from cart by ID.
  - View cart items with total amount.
- Interactive Menu
  - Console-based menu for navigation.
  - Options to view products, add/remove items, and checkout.


## Classes Overview
| Class   | Responsibility |
|---------|----------------|
| `Product` | Represents a product with ID, name, and price. |
| `Cart`    | Manages cart items (add, remove, display, calculate total). |
| `User`    | Handles login authentication. |
| `Amazon`  | Main class with menu-driven program execution. |



## ⚙️ How to Run
  1.compile the program:
  ```bash
    javac Amazon.java
  ```
  2.Run the program
  ```bash
     java Amazon
  ```
